# TP1 - Teoria e Modelo de Grafos

Trabalho da disciplina CCF-331 - Teoria e Modelo de Grafos.

O programa trabalha com grafos nao direcionados e ponderados usando matriz de adjacencia.

## Arquivos

- `grafo.py`: funcoes da biblioteca
- `main.py`: menu para testar as funcoes
- `testes.py`: alguns testes usados na validacao
- `instancias/`: arquivos de entrada usados no trabalho

## Executar

```bash
python main.py
```

Ou passando uma instancia diretamente:

```bash
python main.py instancias/instancia1_pequeno_conexo.txt
```

Para rodar os testes:

```bash
python testes.py
```
